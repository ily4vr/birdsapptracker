# Birds App Tracker
An HTML tracker for Birds app observations. Progress is saved locally in your browser.

Download the HTML file, open it in any browser, and click the dots to record observations. Progress is stored in your browser's local storage — clearing your browser data will reset it. The file must be opened in the same browser each time to retain your progress.

Created for [Birds](https://www.birds.app/) by jules @nicedayJules & mungi @mungimungimungi
